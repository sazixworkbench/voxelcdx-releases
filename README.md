# VoxelCdx

Voxel editor for game developers — model, rig and animate voxel characters and export rigged FBX / glTF with one shared texture for Unity, Unreal and Godot.

**Website:** https://voxelcdx.pages.dev

## Download

| Platform | File |
|---|---|
| Windows 10 / 11 (64-bit) | [VoxelCdx-win-x64.zip](https://github.com/sazixworkbench/voxelcdx-releases/releases/latest/download/VoxelCdx-win-x64.zip) |
| macOS · Apple Silicon (M1 and newer) | [VoxelCdx-macos-arm64.zip](https://github.com/sazixworkbench/voxelcdx-releases/releases/latest/download/VoxelCdx-macos-arm64.zip) |
| macOS · Intel | [VoxelCdx-macos-x64.zip](https://github.com/sazixworkbench/voxelcdx-releases/releases/latest/download/VoxelCdx-macos-x64.zip) |
| Linux x64 | [VoxelCdx-linux-x64.zip](https://github.com/sazixworkbench/voxelcdx-releases/releases/latest/download/VoxelCdx-linux-x64.zip) |

All versions: [Releases](https://github.com/sazixworkbench/voxelcdx-releases/releases).

VoxelCdx is free for modelling, painting and static export. **Pro** (rigging, animation, rigged export, character families, shared material, Unity helper) comes with a free 7-day trial inside the app; licences are sold on the [website](https://voxelcdx.pages.dev/#pricing).

macOS: the app is not notarized by Apple yet — on the first launch open System Settings → Privacy & Security and press **Open Anyway**.
Linux: unzip and run `./VoxelCdx` (run `chmod +x VoxelCdx` if your unzip tool drops the permission).
